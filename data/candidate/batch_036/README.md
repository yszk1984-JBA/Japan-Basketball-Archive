# Batch 036：日本の高校の在学期間（生年月日からの推定）

Yuichiの指示（2026-10-25）「多くの選手の高校生の期間が期間未確認になっていることが多い／日本の高校に進学・卒業している人に関しては、生年月日から推測して高校の期間を設定してください」。追加の判断：サイトでは「推定」と明記して表示する。海外の学校に通った選手は対象外。

ガバナンスの「推測しない」に対する、Yuichiが明示した例外。値はすべて推定値として印を付ける（Evidenceの`issue_note`が「推定値：」で始まる）。公式資料で期間が確認できたら置き換える。

## 算出のルール

日本の学年制：Y年4月2日〜Y+1年4月1日生まれが同学年。高校入学はY+16年4月、卒業はY+19年3月。期間＝開始Y+16、終了Y+19（クラブのシーズンと同じ「開始年・終了年」の書き方）。生年月日はMasterに登録済みの値（ほぼB.LEAGUE公式プロフィール）。

## wave_01

- 推定した高校期間：415件（`master_corrections.csv`、既存Master Careerの期間なし→期間あり）。
- 対象外（`issues.csv`）：海外の学校に通った選手21名、生年月日がMasterにない・複数ある8名。
- 大学の開始年と合わない場合は設定しない設計（今回は該当なし）。
- 浪人・留年・留学生の途中入学などは生年月日だけでは分からないため、実際と違う可能性がある。
