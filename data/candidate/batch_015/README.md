## Wave 1（石橋永遠、菊地広人、藤井祐眞、富田一成）

石橋永遠・菊地広人はいずれもB.LEAGUEデビューから一貫して同一クラブに在籍しており、移籍・空白シーズンともになし。藤井祐眞は現所属（群馬クレインサンダーズ）加入以前に川崎ブレイブサンダースで8シーズンという長い在籍歴を持つ。

富田一成の現所属は金沢サムライズ（新規登録、ORG000205）。これは、batch_011の小栗瑛哉やbatch_014の小川翔矢のプロフィールで「金沢」とだけ記載され正式クラブ名を確認できなかった在籍先（推定として「金沢武士団」と記載していた）と同一の実在クラブである可能性があるが、名称変更・合併等の経緯は今回確認しておらず、過去のissueへの遡及的な修正は行っていない。今後の深掘りWaveでの確認事項として記録する。

## Wave 2（角野亮伍、赤間賢人、最終Wave）

角野亮伍の出身大学はサザンニューハンプシャー大学（米国、新規登録）。赤間賢人はB.LEAGUEデビューから一貫して茨城ロボッツに在籍しており移籍・空白なし。同選手のプロフィール関連動画に「特別指定の大学生プレーヤー」との言及があり、大学在学中の特別指定選手制度での起用の可能性を示唆しているが、契約形態の詳細は資料からは確認できず、Careerデータへの反映（特別な扱い）は行っていない（通常のPlayer roleとして登録）。

## 全Wave共通のデータ上の注意点

各選手とも、高校→大学→現所属クラブの最小経路のみを登録し、現所属クラブ以前のプロ経歴（藤井祐眞・富田一成・角野亮伍）は今回のWaveでは対象外とし、個別にissue（PRO_HISTORY_GAPS）へ記録した（石橋永遠・菊地広人・赤間賢人の3名はB.LEAGUEデビューから移籍・空白のないシンプルな経歴のためissue不要）。高校・大学の入学・卒業年月についても、いずれの資料にも記載がなく全員について未確認のまま（issue HIGH_SCHOOL_PERIOD / UNIVERSITY_PERIOD）。

検証結果は各Waveの`wave_0N/validation_report.md`を参照する。
