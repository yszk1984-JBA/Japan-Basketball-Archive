## Wave 1（藤澤尚之、瀬川琉久、堀陽稀、米須玲音）

瀬川琉久は大学を経由せず、東山高等学校から直接プロ入りした経歴（大学Careerなし、batch_011の平良宗龍と同様のケース）。

藤澤尚之は現所属の熊本ヴォルターズについて、実は過去（2020-21・2021-22）にも同クラブに在籍しており、その後奈良・福井を経て2026-27シーズンに熊本へ復帰した形。同一クラブへの復帰時のCareer開始年は現在の連続在籍開始年とする既存の方針（batch_010の津屋一球などと同様）に従い、開始年を2026年とした。また、公式のクラブ所属履歴には2023-24シーズンの記載が一切なく（2024-25福井の次が2022-23奈良）、理由不明の空白シーズンとして憶測で埋めずissueに記録した。

米須玲音（2003年1月生）は公式のクラブ所属履歴上、2020-21・2021-22シーズンに川崎ブレイブサンダースへの在籍記録があるが、この時期は本人が東山高等学校在学中とみられ、高校生年代での特別な起用の可能性があるものの契約形態は資料からは確認できない。続く2022-23・2023-24シーズンは同履歴に記載がなく、大学（日本大学）在学期間と重なる可能性があるがこれも未確認。今回のWaveでは2024-25シーズン以降の現在の連続在籍のみを最小経路として登録した。

## Wave 2（岡田侑大、堀田尚秀、西部秀馬、川嶋勇人、最終Wave）

岡田侑大は三河→富山→信州→京都→島根と5クラブを渡り歩く経歴が特に複雑（issue B13W2I0003）。

川嶋勇人（1990年生、ベテラン）は現所属の京都ハンナリーズについて、2016-17シーズンに同クラブでルーキーとしてプレーした後、三遠・秋田・FE名古屋を経て2024-25シーズンに京都へ復帰した形。藤澤尚之と同様、同一クラブへの復帰として現在の連続在籍開始年（2024年）を登録した。

## 全Wave共通のデータ上の注意点

各選手とも、高校→大学（該当者のみ）→現所属クラブの最小経路のみを登録し、現所属クラブ以前の複数のプロ経歴（該当者多数、特に岡田侑大・川嶋勇人は経歴が長い）は今回のWaveでは対象外とし、個別にissue（PRO_HISTORY_GAPS）へ記録した。高校・大学の入学・卒業年月についても、いずれの資料にも記載がなく全員について未確認のまま（issue HIGH_SCHOOL_PERIOD / UNIVERSITY_PERIOD）。

検証結果は各Waveの`wave_0N/validation_report.md`を参照する。
