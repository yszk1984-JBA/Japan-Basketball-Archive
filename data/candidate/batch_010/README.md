# Batch 010

作成日：2026-09-24

状態：洛南高等学校の対象19人（Wave 1〜4）についてCANDIDATE・構造QA完了。HUMAN APPROVAL・VERIFIED・MASTER・公開は未実施。

## 位置づけ

福岡第一高校以外の強豪校へ体系的に対象を広げる取り組みの学校3/11。詳細な選定方法・対象11校・スコープは[`docs/BATCH_008_PROPOSAL.md`](../../../docs/BATCH_008_PROPOSAL.md)を参照する。batch_008（大濠）・batch_009（明成/仙台大学附属明成）に続き、学校ごとにbatchを分けるためbatch_010とした。

## 発見方法上の重要な知見（全Wave共通）

B.LEAGUE公式のTagID=35:洛南高等学校タグ一覧は「検索結果：23人」と表示されるが、静的HTML取得（WebFetch）では18人分しか表示されず、残り5人はJavaScript製の「もっと見る」ボタン（`javascript:more();`）の先にのみ表示される。WebFetchはJS実行ができないため、インタラクティブなブラウザツール（built-in browser）に切り替え、ボタンをクリックして全23人分を取得した。この過程でCookie同意バナーが表示され、プライバシー保護原則に基づき「同意しない」を選択した。

23人のうち、既存登録済みで現在の所属クラブまで経歴が完備している4名（星川堅信、竹内譲次、辻直人、比江島慎）を除く19名が今回の対象。

同タグ一覧の選手カードの「出身校」欄は、対象校のタグでフィルタされていることを前提に、実際には出身**大学**を表示している（高校名は表示されない）ことをWave 1で発見し、以降のWaveでは個別プロフィール取得の手間を省く手掛かりとして活用した。

## Wave 1（星川開聖、竹内公輔、荒川颯、笹山貴哉、岩屋頼、森井健太）

竹内公輔について、所属クラブ名が資料により「栃木ブレックス」「宇都宮ブレックス」と表記が分かれていたため、WebSearch（日経、basketballking.jp）で2019年7月の改称（同一クラブ）であることを確認したうえで、既存Organization（ORG000047）を再利用し、Career開始年は実際の加入年である2016年とした（改称タイミングの2019年ではない）。改称履歴を単一名称スキーマで表現できない点はissue B10W1I0006に記録した。

笹山貴哉のクラブ経歴に登場する「名古屋D」について、ファイティングイーグルス名古屋（FE名古屋）の改称後の略称ではないかを検証した結果、FE名古屋公式の「呼称変更のお知らせ」で法人名・クラブ名は変更していない（2020年のニックネーム変更のみ）ことを確認し、「名古屋D」は全く別のクラブである名古屋ダイヤモンドドルフィンズ（ORG000054、batch_007で登録済み）を指すことを確認した。栃木/宇都宮とは逆に「同一クラブに見えて実は別クラブ」のケースであり、issue B10W1I0007に記録した。

## Wave 2（淺野ケニー、飯尾文哉、谷口大智、寺嶋良、谷口光貴、大橋大空）

谷口光貴は複数クラブを渡り歩く経歴が特に複雑（issue B10W2I0007）。大橋大空はB.LEAGUE公式プロフィール上、2023-24島根シーズンと2025-26横浜エクセレンスシーズンの間の2024-25シーズンの記載が見当たらず、空白期間の可能性がある。憶測で埋めず、現所属クラブの開始年として確認できる2025年を登録したうえでissue B10W2I0008に記録した。

## Wave 3（大庭岳輝、伊藤達哉、津屋一球、小川敦也、小林遥太、伊藤良太）

津屋一球は三遠ネオフェニックス在籍中に一度離脱（SR渋谷）した後、2024年に三遠へ復帰している。同一クラブへの復帰時のCareer開始年は現在の連続在籍開始年とする既存の方針（納見悠仁・石川海斗などと同様）に従い、開始年を2024年とした。伊藤達哉のクラブ経歴にも「名古屋D」（名古屋ダイヤモンドドルフィンズ、ORG000054）が登場し、Wave 1の知見どおりFE名古屋とは別クラブとして扱った。

## Wave 4（大西一輝、最終Wave）

大西一輝はB.LEAGUE公式タグ一覧上は確認できたが、タグ一覧のカードおよびヴィアティン三重のclub_detailロスターページの双方がリンクする`PlayerID=11482`のroster_detailページは、実際には全く別人（ザック・モーア、1997年3月26日生、元UCサンタバーバラ/UBC）のプロフィールを表示するという、B.LEAGUE公式サイト自体のバグを発見した。このPlayerIDはソースとして採用せず、代わりにヴィアティン三重公式サイト（veertien-basketball.jp）とファンサイトを一次情報として採用した（issue B10W4I0004）。

また、同姓同名で環太平洋大学出身の別のバスケットボール選手が球歴.comに掲載されていることを確認したが、生年月日（2003年10月25日）の一致により、洛南高等学校・中京大学出身の本人とは別人であることを確認した上で混同を避けた。

ヴィアティン三重への加入年はいずれの資料にも記載がなく未確認のためNULLのまま登録し、issue B10W4I0003に記録した。

## 全Wave共通のデータ上の注意点

各選手とも、高校→大学→現所属クラブの最小経路のみを登録し、現所属クラブ以前の複数のプロ経歴（該当者多数、特に伊藤達哉・小林遥太・伊藤良太は経歴が長い）は今回のWaveでは対象外とし、個別にissue（PRO_HISTORY_GAPS）へ記録した。高校・大学の入学・卒業年月についても、いずれの資料にも記載がなく全19名について未確認のまま（issue HIGH_SCHOOL_PERIOD / UNIVERSITY_PERIOD）。

検証結果は各Waveの`wave_0N/validation_report.md`を参照する。

これにより洛南高等学校（学校3/11）はCANDIDATE段階まで到達した。次のステップはQA→VERIFIED→HUMAN APPROVALで、Yuichiの指示を待つ。
