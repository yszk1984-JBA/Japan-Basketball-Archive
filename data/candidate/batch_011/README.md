## 発見方法上の重要な知見（今後の学校5〜11の参考用）

これまでのbatchでは「TagID=35」を洛南高等学校固有の番号のように扱っていたが、今回の調査で**TagID=35は「出身校」タグの共通カテゴリー番号**であり、実際の絞り込み条件はコロン以降の学校名部分（URLエンコード）であることが判明した（例：`TagID=35:洛南高等学校`、`TagID=35:開志国際高等学校`）。また、B.LEAGUE公式サイトの「ワタシノB.LEAGUE」トップの「絞り込み」モーダル（特徴／基本情報／クラブの3タブ）には「出身校」を直接選べるUIが存在しない。今回は既知の在籍者（平良宗龍）の個別プロフィールページ（roster_detail）に掲載されている「出身校」リンクのhrefから、開志国際高等学校のタグURLを特定した。この方法は学校5〜11でも再利用できる（対象校の在籍者を1人でも特定できれば、そのプロフィールページから出身校タグURLを逆引きできる）。

## Wave 1（介川アンソニー翔、小栗瑛哉、平良宗龍、最終Wave）

TagID=35:開志国際高等学校のタグ一覧には3人のみが表示され、「もっと見る」ボタンは存在しなかった（＝この3人が開志国際高等学校出身の現役B.LEAGUE選手の全員）。これまでの大濠・明成・洛南と比べて大幅に小規模なbatchとなった。

介川アンソニー翔は専修大学を経て2024年に島根スサノオマジックへ加入。プロフィール上の身長・体重・ポジション（SF/PF、197cm/93kg）は、本プロジェクトのPersonスキーマが氏名・生年月日のみを対象としているため登録していない。過去のbatchと同様の扱いだが、身長・体重等をスキーマに含めるべきかは検討事項としてissue B11W1I0003に記録し、Yuichiの判断を仰ぐ。

小栗瑛哉は大阪産業大学を経て2025年に信州ブレイブウォリアーズへ加入。ただし信州加入以前に金沢（推定：金沢武士団、正式名称未確認のため未登録）および秋田ノーザンハピネッツ（ORG000137、既存）でのプレー歴があり、今回のWaveでは登録対象外としissue B11W1I0004（PRO_HISTORY_GAPS）に記録した。
