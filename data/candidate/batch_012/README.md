福岡第一高校以外の強豪校へ体系的に対象を広げる取り組みの学校5/11。詳細な選定方法・対象11校・スコープは[`docs/BATCH_008_PROPOSAL.md`](../../../docs/BATCH_008_PROPOSAL.md)を参照する。batch_008（大濠）・batch_009（明成）・batch_010（洛南）・batch_011（開志国際）に続き、学校ごとにbatchを分けるためbatch_012とした。

## 発見方法

batch_011で判明した「TagID=35は出身校タグの共通カテゴリー番号であり、コロン以降の学校名で絞り込む」という知見を活用し、`TagID=35:延岡学園高等学校`のURLを個別プロフィールを経由せず直接組み立てて一発でアクセスできた。今後の学校6〜11でも同様の直接アクセスをまず試す。

## Wave 1（榎田拓真、最終Wave）

TagID=35:延岡学園高等学校のタグ一覧には1人のみが表示され、「もっと見る」ボタンは存在しなかった（＝延岡学園高等学校出身の現役B.LEAGUE選手はこの1人のみ）。近畿大学を経て、直近は山口パッツファイブに所属（2026-27シーズン〜）。

本人のB.LEAGUE公式プロフィールのクラブ所属履歴を確認したところ、2022-23〜2023-24シーズンは長崎、2024-25シーズンは越谷に在籍していたが、その後2025-26シーズンの記載が一切なく、次に記載があるのは2026-27シーズンの山口である。この1年分の空白について公式プロフィール上に説明はなく、移籍空白・登録外・怪我等のいずれであるかは資料からは確認できないため、憶測で埋めずissue B12W1I0003（PRO_HISTORY_GAPS）に記録した。長崎・越谷での過去在籍も同issueに含め、今回のWaveでは対象外とした。

## 全Wave共通のデータ上の注意点

高校→大学→現所属クラブの最小経路のみを登録し、現所属クラブ以前のプロ経歴（長崎・越谷）および2025-26シーズンの空白はissue（PRO_HISTORY_GAPS）へ記録した。高校・大学の入学・卒業年月についても、いずれの資料にも記載がなく未確認のまま（issue HIGH_SCHOOL_PERIOD / UNIVERSITY_PERIOD）。

検証結果は[`wave_01/validation_report.md`](wave_01/validation_report.md)を参照する。

これにより延岡学園高等学校（学校5/11）はCANDIDATE段階まで到達した。次のステップはQA→VERIFIED→HUMAN APPROVALで、Yuichiの指示を待つ。
