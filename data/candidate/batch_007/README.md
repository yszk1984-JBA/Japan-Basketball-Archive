Organizationデータ訂正（ORG000017/ORG000019）と`jba_lib`共通ライブラリ整備の後、Yuichiの承認（2026-09-23、「福岡第一高校に限らないでもBリーグの選手を選んでくれて良いです」）を受けて実施した横展開実験。福岡第一高校経由（Batch 005・006）に限定せず、B.LEAGUE公式サイトを起点に選んだ4人で、[`docs/DATA_SCALING_WORKFLOW_V0.1.md`](../../docs/DATA_SCALING_WORKFLOW_V0.1.md)の標準Wave人数（4人）と最小確認範囲が福岡第一高校以外の選手にもそのまま適用できるかを測る。

## スコープの意図的な限定

各選手の現所属クラブのみをCareerとして記録し、過去の所属クラブ（比江島慎の三河・栃木、齋藤拓実の滋賀・アルバルク東京など）は今回のWaveでは対象外とした。栃木ブレックス→宇都宮ブレックスのような組織名変更・承継の扱いは、Batch 004のB4W3I0011（三菱電機/名古屋ダイヤモンドドルフィンズ）と同じ「OrganizationAlias・組織承継ルール」未解決論点であり、本Waveで別名義のOrganization重複を作らないための切り分け。詳細は[`wave_01/issues.csv`](wave_01/issues.csv)のB7I0010を参照。

## 資料の優先順位

B.LEAGUE公式選手プロフィールおよびクラブ公式選手プロフィールを一次資料として優先し、学校名等の裏付けが公式資料のみで取れなかった2件（篠山竜青：北陸高等学校、齋藤拓実：桐光学園高校）は専門媒体（バスケットボールキング）記事のみを根拠として`SOURCE_TIER`のHOLD Issueに分離した。

検証結果は[`wave_01/validation_report.md`](wave_01/validation_report.md)を参照する。
