# Batch 014

作成日：2026-09-24

状態：北陸高等学校の対象15人（Wave 1〜4）についてCANDIDATE・構造QA完了。HUMAN APPROVAL・VERIFIED・MASTER・公開は未実施。

## 位置づけ

福岡第一高校以外の強豪校へ体系的に対象を広げる取り組みの学校7/11。詳細な選定方法・対象11校・スコープは[`docs/BATCH_008_PROPOSAL.md`](../../../docs/BATCH_008_PROPOSAL.md)を参照する。batch_008（大濠）・batch_009（明成）・batch_010（洛南）・batch_011（開志国際）・batch_012（延岡学園）・batch_013（東山）に続き、学校ごとにbatchを分けるためbatch_014とした。

北陸高等学校は五十嵐圭の母校として選定理由に挙げられているが、B.LEAGUE公式タグ一覧に本人は掲載されていない（現役の登録B.LEAGUE選手ではないためとみられる）。本取り組みは現役B.LEAGUE選手のみを対象とする既定のスコープに従い、五十嵐圭は対象外とした。

北陸高等学校自体は本batch開始前から既にOrganization登録済み（ORG000120、過去のbatchで登録）であることを確認し、新規登録は行わなかった。

## 発見方法上の注意点（学校8〜11の参考用）

対象15人のうち1名（中村ジャズ）の出身大学表記に発見時点でのゆれがあった。本人のB.LEAGUE公式プロフィールでは「国士館大学」（館）と表記されているが、同校出身の寺嶋恭之介（Wave 3）のプロフィールでは正しく「国士舘大学」（舘）と表記されている。実在する大学の正式名称は「国士舘大学」（舘）であるため、B.LEAGUE公式サイト側の誤記と判断し、正式名称の1つのOrganizationとして統合登録した（表記ゆれで同一の実在組織を複数IDに分裂させないため）。判断根拠はevidence_records.csvのissue_noteに明記している。

また、Organization新規登録の判定作業中、「しながわシティバスケットボールクラブ」を一度は新規と誤認して仮IDを割り当てたが、最終検証（構造QAスクリプト）で既存登録（ORG000174、batch_006）との重複が発覚し、既存IDに修正した。この経緯を踏まえ、今後の学校でも構造QAでの重複検出結果を必ず確認してから次のステップに進む。

## Wave 1（高島紳司、野本建吾、大﨑翔太、多嶋朝飛）

野本建吾は現所属の川崎ブレイブサンダースについて、2016-17・2017-18シーズンに一度在籍したクラブへの復帰（間に秋田・群馬を経由）であり、藤澤尚之（batch_013）と同じ既存の復帰時開始年方針を適用した。

## Wave 2（松山駿、松本健児リオン、二上耀、中村ジャズ）

松山駿・二上耀はいずれも今回のWaveで初めて現所属クラブに加入したケースで、過去に同クラブへの在籍歴はない。松本健児リオンは西宮というクラブでの在籍歴があるが、現・神戸ストークスの前身にあたる可能性があるものの組織同一性は未確認のためOrganization登録は行わず、issueに記録するに留めた（2020-21シーズンの記載空白も同様）。中村ジャズは在籍記録が断続的で、複数シーズンにわたる記載空白がある。

## Wave 3（寺嶋恭之介、岡田泰希、藤永佳昭、篠山竜青）

篠山竜青はB.LEAGUE初年度（2016-17シーズン）から2026-27シーズンまで一貫して川崎ブレイブサンダース一筋という、この校の中で最もシンプルな経歴（移籍・空白シーズンなし）。藤永佳昭は逆に7クラブを渡り歩く特に長く複雑な経歴を持つ。寺嶋恭之介は2020-21シーズン以降一貫して青森ワッツに在籍しているが、2021-22シーズンのみ記載が空白であり、理由不明として憶測で埋めずissueに記録した。

## Wave 4（髙木慎哉、下地秀一郎、小川翔矢、最終Wave）

下地秀一郎はB.LEAGUEデビュー（2025-26シーズン）から一貫してしながわシティバスケットボールクラブに所属しており、移籍・空白シーズンともになし。小川翔矢は現所属（福島ファイヤーボンズ）加入以前に「金沢」での在籍歴が1シーズンあるが、batch_011の小栗瑛哉と同様、正式クラブ名（金沢武士団とみられる）が未確認のためOrganization未登録のままissueに記録した。

## 全Wave共通のデータ上の注意点

各選手とも、高校→大学→現所属クラブの最小経路のみを登録し、現所属クラブ以前の複数のプロ経歴は今回のWaveでは対象外とし、個別にissue（PRO_HISTORY_GAPS）へ記録した（篠山竜青・下地秀一郎の2名は移籍・空白のないシンプルな経歴のためissue不要）。高校・大学の入学・卒業年月についても、いずれの資料にも記載がなく全員について未確認のまま（issue HIGH_SCHOOL_PERIOD / UNIVERSITY_PERIOD）。

検証結果は各Waveの`wave_0N/validation_report.md`を参照する。

これにより北陸高等学校（学校7/11）はCANDIDATE段階まで到達した。次のステップはQA→VERIFIED→HUMAN APPROVALで、Yuichiの指示を待つ。
