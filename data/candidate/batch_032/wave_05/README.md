# batch_032 Wave 5：クラブ公式サイトによる出身校の追加（CANDIDATE）

作成日：2026-10-04

## 背景

Yuichiの指示（2026-10-04）「出身校が不明な32名 … についても続けて下さい」。2026-27のB.PREMIERロスターにいるMaster登録選手のうち、学校のCareerがない選手（B.LEAGUE公式プロフィールの出身校が「-」）について、各クラブ公式サイトの選手ページを確認した。原文：`data/raw/research/club_profiles_school_2026-10-04.txt`。

対象はすべてbatch_032で登録した人物のため、元のBatchに追加した。

## 結果

- 学校Career 18件（期間は未確認のため空欄）。Organization 15件のうち新規5件（大阪商業大学、サンタマルガリータ・カトリック高校、スカイラインカレッジ、ワシントン州立大学、ノーザンコロラド大学）
- 東京サンロッカーズの7名は選手紹介文の「…出身」「…を経て」の記述から読み取った（issue `SCHOOL_FROM_PROSE`）。中島三千哉の「神奈川大」は略記（issue `SCHOOL_NAME_ABBREVIATED`）
- 深水虎太郎の出身校欄は「千葉ジェッツU18」（ユースチーム）のため学校として登録しない（issue `NON_SCHOOL_ENTRY`）
- クラブ公式サイトの多くは大学のみの記載で、高校は引き続き不明（既存の`SCHOOL_NOT_LISTED` issueはHOLDのまま）

## 対象外

- 佐藤涼成（広島）：クラブ公式サイトにも出身校の記載なし
- ロスターにあるがMaster未登録の4名（18歳未満の登録除外などbatch_032のexcluded.csvの対象）
- 学校Careerが既にある選手（判定の誤検出：海外校名など）
