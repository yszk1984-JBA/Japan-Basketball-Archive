対象：納見悠仁、白戸大聖、菅野ブルース、山内ジャヘル琉人、石川海斗、八村阿蓮。

### 発見方法と注意点

B.LEAGUE公式のTagID=35タグ一覧は、改称の影響で3種類の名称バリアントに分かれて存在した（「明成高等学校(現・仙台大学附属明成高等学校)」「仙台大学附属明成高等学校(旧・明成高等学校)」「仙台大学附属明成高等学校」）。3種類すべてを確認し、既存登録済みの安藤誓哉（P000098、batch_007/wave_05、高校→大学→現所属クラブの経歴が既に完備）を除く5名を発見した。

加えて専門Wiki（j-cbaske.com）とのクロスチェックで、公式タグ一覧のいずれにも掲載されていなかった現役選手・八村阿蓮（神戸ストークス）を追加で発見した。これはタグ一覧のみに頼る発見手法の限界を示す事例であり、issue B9W1I0008に記録した。同Wikiに掲載されている他の卒業生（宮本滉希、畠山俊樹、村田翔、伊藤尚人、宮澤燿佑、伊藤駿ほか）は個別にWeb検索で現況を確認し、いずれも引退済みまたはB.LEAGUE非所属であることを確認したうえで対象外とした。

### データ上の注意点

学校名は2020年4月に「明成高等学校」から「仙台大学附属明成高等学校」へ改称している。既存登録（ORG000147）は改称前の名称「明成高等学校」のままであり、改称後在学とみられる菅野ブルース・山内ジャヘル琉人についても既存IDを再利用し名称は変更していない（既存名称を無断で変更しない方針のため）。単一名称スキーマでは改称履歴を表現できない点をissue B9W1I0007に記録した。

高校・大学とも標準的な最小経路（高校→大学→現所属クラブ）を登録したが、山内ジャヘル琉人は大学情報が確認できなかったため大学のCareerは登録していない（未確認＝NULLの原則）。菅野ブルース・山内ジャヘル琉人・石川海斗は本人のB.LEAGUE公式プロフィールに出身校欄自体が存在せず、タグ一覧やバスケWikiを裏付けとした。石川海斗の出身大学（日本大学）はバスケWikiのみが情報源。

現所属クラブ以前の複数のプロ経歴（納見悠仁、白戸大聖、石川海斗、八村阿蓮が該当。石川海斗は5クラブにまたがる特に長い経歴）は今回のWaveでは対象外とし、個別にissueへ記録した。

検証結果は[`wave_01/validation_report.md`](wave_01/validation_report.md)を参照する。

これにより仙台大学附属明成高等学校（学校2/11）はCANDIDATE段階まで到達した。次のステップはQA→VERIFIED→HUMAN APPROVALで、Yuichiの指示を待つ。
