検証結果は[`wave_01/validation_report.md`](wave_01/validation_report.md)を参照する。

## Wave 2（福岡大学附属大濠高等学校 2/4）

対象：西田陽成、泉登翔、間山柊、針間大知、西田公陽、渡邉伶音。

Wave 1が品質基準（1人あたり公式ソース2件以上、構造QAエラー0件、人物誤認0件）を満たしたため、`docs/RESEARCH_BATCH_SIZING_V0.1.md`のルールに基づきWave人数を標準4人から6人へ増やした。同じく高校→大学→現所属クラブの最小経路のみを登録。西田公陽の徳島ガンバロウズ在籍はシーホース三河からの期限付移籍（ローン）の可能性、渡邉伶音は東海大学へ進学後に中退しアルティーリ千葉と契約という複雑な経歴（大学在籍自体はCareerとして登録、進学前の特別指定選手期間は対象外）を、それぞれissueに記録した。

検証結果は[`wave_02/validation_report.md`](wave_02/validation_report.md)を参照する。

## Wave 3（福岡大学附属大濠高等学校 3/4）

対象：木林優、湧川颯斗、中田嵩基、平松克樹、岩下准平、浅井修伍。

同じく高校→大学→現所属クラブの最小経路のみを登録（湧川颯斗は大学に進学していないため高校→現所属クラブの2段のみ）。木林優は本人のB.LEAGUE公式プロフィールに学歴欄自体が存在せず、Wikipediaを主ソースとし出身校タグ一覧で高校のみ裏付けた。岩下准平は本人プロフィールの出身校欄が空欄のため報道記事で大学（筑波大学、契約当時4年生）を確認し、かつ原契約は長崎ヴェルカで滋賀レイクスへは「育成契約選手制度」による特別指定選手・期限付移籍という西田公陽と同様の未整備事項をissueに記録した。木林優・湧川颯斗・中田嵩基・浅井修伍の4名については現所属クラブ以前のプロ経歴（各1クラブ）を対象外とし、個別にissueへ記録した。

検証結果は[`wave_03/validation_report.md`](wave_03/validation_report.md)を参照する。
