### SRC000023

- タイトル：`2021年度新入生紹介③ : CHUO BASKETBALL`
- 発行元：中央大学学友会体育連盟バスケットボール部
- 原本URL：<http://blog.livedoor.jp/chuo_basket/archives/55638062.html>
- 確認結果：HTTPからHTTPSへ転送されるが、今回の取得環境では転送先が502となり本文を確認できなかった。
- 判定：要再確認。URLが無効であるとは断定しない。

## 対応

- `%3D`を含む10件は修正候補から除外する。
- SRC000023はブラウザでの人間確認またはWebアーカイブ確認の対象とする。
- URL到達だけでは記事内の各事実を検証済みとしない。項目別の該当箇所は別途Evidenceとして確認する。
- Excel原本、Sourceデータ、Schema、Masterは変更しない。
