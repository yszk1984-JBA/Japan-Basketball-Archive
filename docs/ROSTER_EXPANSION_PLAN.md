# ロスター起点の横展開 計画（B.PREMIER 2026-27）

## 背景

Yuichiの指示（2026-09-29）「公開サイトにデプロイしてから、クラブのロスター起点に選手を追加します」。これまでの横展開は出身校（強豪校）を起点にしていたが、今回はB.LEAGUE公式の選手一覧（クラブ別ロスター）を起点に、現役選手を網羅的に登録する。

| 帰化選手 | 含める（公式の国籍区分「日本」どおり） |

## 手順

1. 公式選手一覧 `/roster/?year=2026&club=<TeamID>&c=日本&e=在籍中` を26クラブ分取得（253名）。MasterのSourceにあるPlayerIDと照合して、未登録148名・batch_007の未承認候補25名を抽出
2. 対象173名の公式プロフィール（生年月日・出身校（高）・出身校（大）・クラブ所属履歴）をブラウザで取得し、原文を `data/raw/research/` に保存
3. 新規人物は `data/candidate/batch_032`（40名ずつのWave）、batch_007の再確認は元Batchの `batch_007/wave_11` に登録（深掘りログの「元の登録Batchに追加する」ルール）
4. 検証 → VERIFIED → Approval Sprint 009（2段階承認、Tier案は自動）

## 登録ルール

- 18歳未満は登録しない（2段階承認の採用時の条件）
- 学校：出身校欄に書かれた学校ごとに1件のCareer（期間は未確認のため空欄）。「(現・…)」は注記として扱い、改称前後の名称は1つのOrganizationにまとめる（能代工業→能代科学技術と同じ扱い）。表記ゆれ（付属／附属、「高校」／「高等学校」など）は既存Organizationに寄せる
- クラブ：batch_031と同じ（`scripts/jba_lib/bleague_history.py`）。公式順位表で略称をTeamIDに対応付け、同じTeamIDの改称クラブは1つのOrganization
- 所属履歴の空白年は推測しない（Yuichi、2026-09-26）
- batch_007の再確認：学校Careerは残す。期間未記録の現所属Careerは、公式所属履歴から作った期間付きCareerに置き換え（旧CareerはREJECT_CANDIDATE）
