## 最小確認範囲

各人物について次を確認する。

1. 公式資料上の氏名と表記揺れ
2. 福岡第一高校での役割、学年、背番号、ポジション、身長
3. 高校で確認できる最古・最新の活動日
4. 卒業後の組織への実所属と競技参加
5. 卒業後の組織で確認できる最古・最新の活動日
6. Sourceの直接URL、発行元、資料内位置、原文
7. 人物同定、期間、資料間矛盾などのIssue
