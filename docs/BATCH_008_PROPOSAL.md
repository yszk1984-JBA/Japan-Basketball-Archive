# BATCH_008_PROPOSAL — 強豪校横展開（福岡第一高校以外）

作成日：2026-09-24

## 背景・目的

Yuichiからの指示（2026-09-24）「福岡第一以外に有名強豪高校を10個ピックアップして、その高校の卒業生とB LEAGUEや大学とどう繋がっているかを追加していきたい」を受けた新しい横展開の取り組み。これまでのBatch 002〜007は福岡第一高校を起点とする選手が中心だった（Batch 007のWave 1のみ、福岡第一高校に限らないB.LEAGUE選手選定の実験）。本Batchでは、対象を「福岡第一以外の強豪校」に明示的に広げ、学校単位で体系的にB.LEAGUE・大学とのつながりを追加していく。

## 対象校の選定方法

ウインターカップの優勝実績、B.LEAGUE選手輩出実績、地域バランスをもとに、Web検索で複数の独立した情報源（バスケットボールキング歴代優勝校一覧、「考えるバスケットの会」強豪校ランキング、すぽろぐ強豪校紹介記事）を突き合わせて11校を選定し、Yuichiに確認のうえ決定した（2026-09-24、AskUserQuestionでの回答）。

## スコープ（Yuichi承認、2026-09-24）

- **調査対象**：各校出身で**現役のB.LEAGUE選手のみ**。引退選手・大学バスケ現役選手は対象外（将来ラウンドで検討）。
- **Career範囲**：福岡第一高校バッチと同じ最小経路（高校→大学→現所属クラブの3段階のみ）。現所属クラブ以前の複数のプロ経歴は、深掘りWaveの対象として個別にissue化する。
- **進め方**：10校（実際は11校）まとめてではなく、**1校ずつ**取り組み、都度Yuichiに報告する。
- **選手選定の起点**：各校について、B.LEAGUE公式サイトの「ワタシノB.LEAGUE選手一覧」（出身校タグ機能）を第一の起点とする。該当校のタグ一覧に掲載された選手のうち、既存Batchで未登録の人物を対象とする。
- **Wave人数**：`docs/RESEARCH_BATCH_SIZING_V0.1.md`の標準（4人/Wave）に従う。1校あたりの対象人数が多い場合は、同一Batch内で複数Waveに分割する。
