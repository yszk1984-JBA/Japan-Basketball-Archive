# PROJECT — Governance v1.0

## 目的

日本のバスケットボールに関わる人物と所属・キャリアの記録を、検証可能な出典とともに蓄積する。初期パイロットは既存の福岡第一高校データとする。

## 初期範囲

Person / Career / Organization / Sourceを中心とするデータ設計v0.1と運用ルールを定める。今回の成果物はREADME.md、AGENTS.md、docs/内の5文書。既存Excelの内容や品質は未確認であり、件数・人物・経歴を推定しない。

試合・成績などの追加エンティティ、データベース構築、サイト開発、大規模収集、公開は今回の範囲外。データ形式・技術構成はパイロット確認後に決める。

## 責任

OwnerのYuichiが最終判断、Human verification、Master approvalを担当する。AIは調査、設計、整理、QA、自動化を支援する。役割の詳細は[AI_WORKFLOW](AI_WORKFLOW.md)を参照。

## 成功条件

出典から候補データを再確認でき、不明点と矛盾が可視化され、人間の明示的承認なしにMasterへ進まないこと。文書の承認と個別データの承認を区別する。
