# Batch 004 — 福岡第一高校からプロへの経路

作成日：2026-09-20

## 状態

調査対象案。データ取込、Schema拡張、VERIFIED、HUMAN APPROVAL、MASTERは未実施。

## 目的

福岡第一高校をコアにしながら、B.LEAGUE、B3、B.NEXT、NBA等でプロCareerを確認できる人物を優先する。既存バッチで扱った人物も、大学までの経路からプロCareerへ移った場合は新しいSourceとCareer候補を追加する。

現在のB.LEAGUE公式「出身高校：福岡第一高等学校」一覧11人はPilot Batch 001とBatch 002ですべて調査対象にした。Batch 004では、その一覧から漏れやすいB3、特別指定、海外、引退したプロ経験者、ドラフト候補を調べる。

## 優先順位

1. 現在のプロ契約を公式発表で確認できる人物
2. B.LEAGUE、B3等の公式戦出場を確認できる人物
3. 過去のプロCareerを公式資料で確認できる人物
4. B.LEAGUEドラフト公式候補

ドラフト候補はプロ選手として扱わない。契約、登録、公式戦出場はそれぞれ別のEvidenceとして記録する。

## 1人あたりの最小確認範囲

1. 公式な氏名と表記揺れ
2. 福岡第一高校との関係を示す公式資料
3. 高校後の大学・組織
4. プロ契約、選手登録、公式戦出場のうち確認できる事実
5. 各Careerの時点または期間
6. Sourceの直接URL、発行元、資料名、公開日、資料内位置
7. 未解決の期間、人物同定、表記、契約状態

## 判定上の注意

- 契約発表だけで公式戦出場済みとは扱わない。
- 特別指定選手を卒業後の本契約と扱わない。
- ドラフト候補を指名済み・契約済み・プロ選手と扱わない。
- 「現在所属」は確認日の値として記録し、過去Careerを上書きしない。
- 高校・大学の開始年と終了年を学年から機械的に逆算しない。
- B.LEAGUE記事、クラブ発表、大学資料が矛盾する場合はSourceごとに値を保持してHOLDにする。
