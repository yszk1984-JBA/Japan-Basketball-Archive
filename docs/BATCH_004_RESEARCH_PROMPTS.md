# Batch 004 — Felo・Gemini調査指示文

対象は[BATCH_004_PROPOSAL](BATCH_004_PROPOSAL.md)の10人。調査AIの回答文自体はSourceにせず、返されたURLと資料内位置をCodexが再確認してからCANDIDATE化する。

## Felo用：公式資料の発見

```text
福岡第一高校を経由してプロまたはB.LEAGUEドラフト候補になった次の10人について、公開情報を調査してください。

対象：
1. 河村 勇輝
2. 児玉 ジュニア
3. 河合 瑠那
4. 長岡 大杜
5. 重冨 周希
6. 重冨 友希
7. キエキエ トピー アリ
8. 遥 天翼
9. 今泉 太陽
10. 崎濱 秀真

目的は、福岡第一高校 → 大学等 → プロ／ドラフト候補の経路を、公式資料の直接URLから確認することです。

優先する発行元：
- B.LEAGUE、B3リーグ、NBA、JBA
- 所属クラブ公式サイト
- 大学・学校公式サイト
- 大学バスケットボール連盟、大会主催者

人物ごとに次を表で提出してください。
- 氏名
- 確認対象の組織・Career
- 確認できた値
- 発行元
- ページ名・資料名
- 公開日または大会日
- トップページではない直接URL
- ページ番号、見出し、選手欄等の資料内位置
- 資料内の具体的記載の短い要約
- 公式資料／二次資料の区別
- 不明点、矛盾、表記揺れ

必須ルール：
- 検索結果URLやGoogle検索URLを直接URLとして提出しない。
- Wikipedia、まとめサイト、AI回答を公式確認に使わない。
- 契約発表、選手登録、公式戦出場、ドラフト候補を区別する。
- 現在所属は確認日を付け、過去所属を消さない。
- 見つからない値は推測せず「不明」とする。
- 同姓同名の可能性を確認する。

最後に、検索語、検索した公式ドメイン、確認日を記載してください。
```

## Gemini用：公式資料の精査

```text
以下の10人について、Feloが発見したURLと追加の公式資料を精査してください。

対象：河村勇輝、児玉ジュニア、河合瑠那、長岡大杜、重冨周希、重冨友希、キエキエ トピー アリ、遥天翼、今泉太陽、崎濱秀真

目標：Person / Career / Organization / Sourceへ登録できる項目と、HOLDにする項目を分離すること。

人物ごとに確認してください。
1. 公式な氏名、読み、英語表記、生年月日
2. 福岡第一高校で確認できる最古・最新の活動時点
3. 高校後の大学・組織と公式の競技参加
4. プロ契約の種別と発表日
5. リーグ登録と登録時期
6. 公式戦出場記録の有無と最初に確認できる試合
7. 現在または最後に確認できる所属
8. 表記揺れ、同一人物性、資料間の矛盾

出力表の列：
人物｜対象項目｜確認値｜発行元｜ページ名・資料名｜公開日・大会日｜直接URL｜ページ番号・資料内位置｜資料内の具体的記載｜判定

判定：
- READY_FOR_VERIFIED_REVIEW：公式資料の該当箇所で値を直接確認でき、矛盾がない
- HOLD_CANDIDATE：出典不足、矛盾、人物同定、期間等が未解決
- REJECT_CANDIDATE：別人、誤記、無関係資料

必須ルール：
- 契約発表だけで出場済みと判定しない。
- 特別指定選手を卒業後の本契約と扱わない。
- ドラフト候補をプロ契約済みと扱わない。
- 学年から入学・卒業年月を逆算しない。
- B.LEAGUE MEDIA NEWSが外部記事の転載である場合、クラブ公式の一次発表も探す。
- 直接URLと資料内位置がない情報はREADYにしない。
- 推測、一般論、可能性だけの文章を確認値にしない。

人物ごとに、採用可能項目、HOLD項目、追加で人間確認が必要な点を最後にまとめてください。
```

## Codex受入時の確認

- URLが実在し、対象人物の記載があるか
- 発行元、公開日、資料名が回答と一致するか
- 引用要約が実際の記載を超えていないか
- 契約、登録、出場、在籍を混同していないか
- 既存Person IDとの重複がないか
- 同じSourceでも項目別の資料内位置が記録されているか
