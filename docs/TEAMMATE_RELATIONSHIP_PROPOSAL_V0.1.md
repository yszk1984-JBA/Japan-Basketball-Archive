# 同時所属・チームメイト関係機能案 v0.1

作成日：2026-09-21

状態：将来設計案。スキーマ拡張・データ追加・公開実装は未承認。

## 目的

人物ページから、中学・高校・大学・B.LEAGUE等で同じ時期に同じ学校・クラブへ所属していた人物をたどれるようにする。同じ試合への出場や同時出場は対象にしない。

例：河村勇輝のページに、福岡第一高校で同時期に所属した人物として小川麻斗を表示する。ただし、両者の所属年度をSourceで確認できた場合に限る。

## 基本方式

人物同士の関係を手入力するのではなく、承認済みCareerから計算する。

```text
人物AのCareer ─┐
                ├─ 同じOrganization + 重なる期間 → 同時所属候補
人物BのCareer ─┘
```

これにより、中学・高校・大学・プロクラブを同じ仕組みで扱える。人物の追加やCareerの訂正があった場合も、関係を再計算できる。

所属期間に加えて、大会公式ロスターに複数人物が同じチームのメンバーとして掲載されている場合は、「同一大会・同一チーム登録」を直接確認できる。期間の開始・終了が不明でも、その大会時点に限定した関係を記録できる。

## 確認できた試験例

[SoftBank ウインターカップ2018 福岡第一高等学校チームページ](https://wintercup2018.japanbasketball.jp/team/m19/)のプレイヤー表には、同じ福岡第一高校の登録メンバーとして次の記載がある。

- No.8 河村 勇輝
- No.46 小川 麻斗

この資料からは「両者がウインターカップ2018の時点で福岡第一高校の同じチームに所属していた」と確認できる。本機能では、個別試合への出場や同時出場は確認対象にしない。

## 表示する関係

| 表示 | 条件 |
| --- | --- |
| 同じ組織に所属 | 同一Organizationへの所属を確認できる |
| 同じ年度に所属 | 両者の所属期間が同じ年度に重なる |
| 同じ時点のチーム登録 | 同一時期・同一チームの公式ロスター等で両者を確認できる |

「同じ学校の出身」と「同じ時期に同じ学校・クラブへ所属」は分けて表示する。学校への在籍だけが確認でき、部活動所属が確認できない場合は、同じチーム所属とは断定しない。

## 必要なデータ

現在のCareerにあるperson_id、organization_id、role、start、endを基礎にする。将来、次の項目を追加候補として検討する。

- season：例 `2025-26`
- period_start / period_end：確認できた精度を保持した期間
- period_precision：日、月、年、年度、シーズン等
- membership_type：学校在籍、部活動登録、選手登録、練習生等
- squad：Aチーム、Bチーム、年代別チーム等
- roster_source_id：同一大会ロスターを裏付けるSource

項目の追加はデータ設計v0.1の正式変更ではない。小規模試験後にYuichiと合意する。

## 判定ルール

1. 同一人物・同一組織のIDが確定している。
2. 両者の期間に重なりがあることを、同じ精度で比較できる。
3. 期間と所属にSourceが付いている。
4. HOLDの期間を推測で補わない。
5. 同じ組織でも部門・男女・年代・A/Bチームが異なる場合は自動でチームメイトにしない。
6. 移籍、期限付き登録、特別指定、練習生等は登録区分を表示する。

期間が不明な場合は、関係探索の候補として内部確認できても、公開画面では「同時期」と表示しない。

## 生成する関係データの案

関係はMasterの原本として手入力せず、Master Careerから生成する派生データとする。

| 項目 | 内容 |
| --- | --- |
| person_id_a / person_id_b | 対象人物 |
| organization_id | 共通する組織 |
| career_id_a / career_id_b | 計算元Career |
| overlap_start / overlap_end | 確認できた重複期間 |
| overlap_precision | 年度、年、月等の精度 |
| relationship_type | 同一組織、同年度、同一ロスター等 |
| source_ids | 判定に使用したSource |
| generated_from_version | 使用したMaster版 |

## 画面案

人物ページのCareerごとに「同じ時期に同じ学校・クラブへ所属した人物」を表示する。

```text
福岡第一高校　2018〜2019年度
同時期に所属：小川麻斗、○○○○
根拠：大会公式ロスター、学校・クラブ公式資料
```

組織ページでは年度を選び、その年度に確認できた人物を一覧にする。関係から相手の人物ページへ移動できるようにする。

## 小規模試験

最初は福岡第一高校の5〜10人を対象にする。

1. 各人物の高校Career期間をSource付きで確認する。
2. 同じ年度のロスター資料で両者の登録を照合する。
3. 派生関係を生成する。
4. 誤判定、期間不足、A/Bチーム混同を確認する。
5. 結果を見てスキーマ拡張と公開範囲を合意する。

河村勇輝と小川麻斗は最初の試験対象とする。現在のMasterでは両者の福岡第一高校Careerの開始・終了年が空欄のため、在籍期間全体の重複は未確認である。一方、ウインターカップ2018公式ロスターに両者が掲載されているため、「同一大会・同一チーム登録」はCANDIDATEとして作成できる。個別データとして公開する場合は通常のGovernance工程を通す。

## Governance

関係データもRAW → CANDIDATE → QA → VERIFIED → HUMAN APPROVAL → MASTERの承認済みCareerを基礎にする。派生計算が正しくても、元Careerの未確認値を補う根拠にはしない。生成結果から使用したCareerとSourceへ戻れるようにする。
